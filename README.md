# Athena Core

Athena Core is the foundation for SellerPilot: a personal AI operating system for Amir's Amazon business.

## Mission

Build an AI business operator that can observe the business, explain what is happening, recommend actions, execute approved actions, and learn over time.

## Core principles

- Decisions over dashboards
- Explainability before automation
- Trust before autonomy
- Domain-driven design
- Event-driven architecture
- One source of truth

## Initial scope

This repository starts with the engineering foundation:
- product and UX specification
- architecture blueprint
- domain model
- engineering standards
- ADR records

## Planned stack

- Frontend: Next.js + TypeScript
- Backend: FastAPI + Python
- Database: PostgreSQL + pgvector
- Cache / queue: Redis
- AI orchestration: LangGraph
- Infrastructure: Docker, GitHub Actions, AWS
